SiteAlive Contact v5

1. contact.js болон contact.html файлыг localhost/sitealive дахь хуучин файлуудын оронд хуулна.
2. apps-script/Code.gs файлыг текст засварлагчаар нээгээд БҮХ кодыг хуулна.
3. Google Sheets → Extensions → Apps Script → Code.gs: хуучин кодыг БҮХЭЛД нь сольж тавина. Нэмж залгаж болохгүй.
4. Ctrl+S → Deploy → Manage deployments → Edit → Version: New version → Deploy.
5. Одоо байгаа deployment-ийг шинэчилсэн бол contact-config.js хаягийг солихгүй.
6. localhost/sitealive/contact.html дээр Ctrl+Shift+R дараад нэг санал илгээнэ.

Шинэ арга: POST хүсэлтээр санал хадгална. Iframe-ийн баталгааг сонсоно; хариу ирэхгүй бол 5 секундийн дараа хүсэлтийн ID-аар хадгалалтын баримтыг шалгана. Зөвхөн Sheets-д байгаа ID батлагдсан үед амжилт харуулна. Нөөц шалгалт нь саналын текст, имэйл, утас зэрэг мэдээллийг буцаахгүй.
45 секундэд баталгаа ирэхгүй бол амжилт гэж худал харуулахгүй. Дахин илгээхэд ижил ID-г ашиглаж давхар мөр үүсгэхээс хамгаална (хуудсыг шинэчлээгүй үед).
